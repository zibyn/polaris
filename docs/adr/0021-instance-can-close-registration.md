# 实例可以关闭开放注册

不变式 2「登录即注册」原本不提供关闭开关。现在增加实例级的「开放注册」,默认开启,行为与原来一致。关闭之后,验证码登录遇到池内不存在的 Identifier 时直接拒绝,**不发验证码**;External Identity 首次登录同样拒绝。初始化页、管理员创建 User 和注册邀请照常可用。这样做有两个原因:一是员工系统这类实例本来就不该让陌生人进来,同类平台(Auth0、Logto、Authing)也都提供这个开关;二是它可以在全实例每日发送上限被随机号码刷光时止血(#144)。

## Considered Options

- **按新老 User 给每日发送上限分层**(#144):主流平台都没有这样做,还会多出一个设置项,并且在新号额度用完期间暴露号码是否已注册。关闭注册的代价更小。
- **单独设一档「仅邀请」**:关闭注册后,新 User 本来就只剩管理员创建和邀请这两条路,再设一档只是同一件事换个名字。

## Consequences

- 关闭注册时,拒绝提示会暴露某个手机号或邮箱是否已注册。这是管理员主动选的,可以接受。
- 关闭注册后,已有 User 在账号中心绑定新 Identifier 不受影响:这不是注册。
