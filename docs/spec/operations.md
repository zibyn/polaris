# 运维与发布

## 许可证

Apache-2.0。并入的 go-oidc(MIT)保留其版权声明。(ADR 0008)

## 发布物

- **镜像**:多架构(amd64 + arm64),主仓库为 GHCR;同步推送一份到阿里云 ACR 个人版(三期起),方便国内拉取。不推送 Docker Hub。
- **二进制**:GitHub Releases 附各平台的单个二进制。

## 版本与升级

- **版本号**:SemVer。一期、二期为 0.x;**1.0 即通过 OpenID 认证的版本**。
- **迁移脚本**:永不删除、永不合并,所以任何旧版本都可以直接升级到最新版。
- **降级**:不支持。升级前须先 `pg_dump`。
- **滚动升级**:不支持。升级步骤:停掉全部副本 → 启动新版本(自动迁移)→ 再扩容。

## OpenID 认证

- **CI 回归**:每个 PR 在 GitHub Actions 中用自托管的 conformance suite 跑 Basic OP、Config OP、RP-Initiated Logout 三个计划。
- **正式认证**:在 1.0 时做一次,必须使用 www.certification.openid.net,本地结果不能用于提交。
  - **费用**:先发邮件申请开源费用减免;未获批就按会员价付 $700。
  - **重新认证**:认证不会过期,只在大版本或协议层大改时重新认证。

## 发版节奏

不定期发版。安全修复单独发补丁版本,并通过 GitHub Security Advisories 公告。

## 部署文档最小集合

1. compose 样例:Polaris + PostgreSQL + Caddy(自动签发证书)。
2. 环境变量说明。
3. 醒目的**主密钥备份**提示。
4. `pg_dump` 备份、升级步骤、所有管理员都无法登录时的处理(直接改数据库)。
5. 已知风险(运营商二次放号)与合规提醒(未成年人、数据出境、等保)。
